## 0. 先修正一个外来方案里自相矛盾的地方

方案第 3.1 节说「删除 `ui.py` / `widgets.py` / `theme.py` / `tokens.py` / `anim.py` / `splash.py`」，
第 9.1 节又说「建议保留 `ui_legacy.py` 一个版本，旧入口注释掉」。

**这两条在物理上不能同时成立**：`ui.py` 依赖那 5 个模块，删了模块，`ui_legacy.py`
一 import 就 `ModuleNotFoundError`。所谓"保留 legacy"必须连 3708 行一起保留。

所以只有三个选项：

| 选项 | 代价 | 收益 |
|---|---|---|
| A 保留 legacy + 5 个模块 | 仓库常驻 3708 行死代码，永远要跟着 ruff/依赖一起维护 | WebView2 缺失的机器功能完整 |
| B 全删 | WebView2 缺失的机器没有图形界面 | 仓库干净 |
| C 移到 `legacy/` 子包 | 3708 行还在，只是换了位置；`ui_legacy.py` 里十几处 import 要改 | 主目录干净 |

**推荐 B。** 理由：

1. WebView2 从 Win10 1803（2018-04）起随系统预装，Win11 全系自带。
   2026 年还在用 1803 之前系统的机器，本来就跑不动这个工具的其他部分。
2. 3708 行死代码不是"存着不用"，是**每次改 ruff 规则、每次升 Python 都要陪跑**。
3. 退路不需要留在工作区——W0 已经打了 `git tag tkinter-final`。
   真需要时一条命令就能拿回来：

```bash
git checkout tkinter-final -- ui.py wbn/widgets.py wbn/theme.py \
                               wbn/tokens.py wbn/anim.py wbn/splash.py
```

**降级体验用 B 也能接受**：WebView2 缺失时弹一个原生对话框，告诉用户
"这台机器缺少 WebView2 运行时"，给微软官方下载链接，并提供
「打开配置目录」和「打开日志目录」两个按钮。**能改配置、能看日志，
就是没有图形设置界面**——对一个通知工具来说，这是可接受的降级。

> 如果你更看重"任何机器都能用图形界面"，选 A。但要在 `docs/architecture.md`
> 里写清楚："`legacy/` 下 3708 行是只读历史代码，不接受任何功能改动。"
> 这句话是防止未来有人去"顺手优化"它。

## 1. 自绘标题栏实验（做不做，先看数据）

### 1.1 为什么单独拿出来做实验

方案第 2 节自己写了「自定义窗口边框能做但极痛苦，拖拽、缩放、贴边全要自己写」，
然后 Phase 0 第一句就是 `frameless=True`。这个矛盾要在这一步算清楚。

`-webkit-app-region: drag` 只解决**拖拽**。不解决的：

| 能力 | frameless 下要自己做 |
|---|---|
| 边缘/角落 resize | 8 个方向的命中区 + 手动改窗口尺寸 |
| 双击标题栏最大化 | 自己绑 dblclick |
| Win + ←/→ 贴边 | 系统快捷键，frameless 下行为异常 |
| 拖动到屏幕顶部最大化 | 系统 Aero Snap，要自己实现 |
| 高 DPI 下的命中区 | 边框只有几像素，200% 缩放下更难点中 |

### 1.2 三条验收，全过才做，过不了就永久放弃

| # | 验收 | 通过标准 |
|---|---|---|
| 1 | 四边四角都能拖拽改尺寸 | 每个方向试 3 次，3 次都成功，且不出现"拖到一半卡住" |
| 2 | 双击标题栏最大化 / 还原 | 两次切换都正常，还原后窗口位置正确 |
| 3 | 拖动到屏幕顶部能触发 Aero Snap | 松手后窗口正确最大化 |

**只要有一条不过，就用原生边框。** 原生边框不是"妥协"，Windows 上的
VS Code、Figma、Notion 桌面版全都用原生边框——用户根本不会注意到它。

### 1.3 如果决定做

```html
<header class="titlebar" style="-webkit-app-region: drag">
  <span class="title">AI 任务通知</span>
  <div class="win-btns" style="-webkit-app-region: no-drag">
    <button data-win="min">—</button>
    <button data-win="max">□</button>
    <button data-win="close">✕</button>
  </div>
</header>
```

```python
# bridge 里补三个
def win_min(self): self._window.minimize()
def win_max(self): 
    # pywebview 的 maximize 在 frameless 下行为依赖版本，先实测
    ...
def win_close(self): self._window.destroy()
```

`no-drag` 必须加在按钮上，否则点按钮会变成拖窗口。

## 3. 降级路径（选 B 才需要）

```python
# app.py
def fallback_no_webview() -> None:
    """没有 WebView2：给一个能改配置、能看日志的原生对话框。

    用 ctypes 调 MessageBoxW，**不许 import tkinter**——W7 要把 exe 打出来，
    带上 tkinter 会多 5MB，还会拖慢启动。见 W7 §0.2。
    """
    import ctypes
    MB_YESNO, MB_ICONWARNING = 0x04, 0x30
    r = ctypes.windll.user32.MessageBoxW(
        None,
        "这台机器缺少 Microsoft WebView2 运行时，设置界面无法启动。\n\n"
        "通知功能不受影响，仍然正常工作。\n\n是否打开配置目录？（可手动编辑 config.json）",
        "缺少 WebView2 运行时",
        MB_YESNO | MB_ICONWARNING,
    )
    if r == 6:      # IDYES
        os.startfile(str(config.ROOT))
```

**这条降级路径要真的能走通**：W5 验收第 5 条要求临时删掉注册表键、
启动、看到提示框、恢复。写代码不算，跑通才算。
