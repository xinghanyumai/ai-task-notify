# 飞书群机器人（feishu_bot）

填一个 Webhook 就完事。

## 申请步骤

1. 飞书群设置 →「群机器人」→「添加机器人」→「自定义机器人」。
2. 复制 Webhook 地址。
3. 填进设置中心，点「测试此通道」。

## 字段

| 字段 | 说明 |
|---|---|
| `webhook` | 机器人地址，形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxx` |

## 这个通道的坑

- 发的是纯文本，不是 markdown。飞书自定义机器人的 `text` 类型只吃纯文本，markdown 语法会原样显示成星号和井号。想要富文本得用 `interactive` 卡片，那需要按飞书卡片 JSON 结构拼，本程序没做。需要排版就走 [企业微信自建应用](wecom-app.md)。
- 安全设置要留意。飞书也支持关键词、签名、IP 白名单三种，选了签名的话 本通道填不进去，因为字段里没留签名位。用关键词或 IP 白名单，或者干脆都不选 （仅限内部群）。
- 成功返回有两种格式。飞书有时返回 `code: 0`，有时返回 `StatusCode: 0`，程序两种都认。
