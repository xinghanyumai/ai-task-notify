# 钉钉群机器人（dingtalk_bot）

和微信群机器人一个思路，多了一个可选的加签。

## 申请步骤

1. 钉钉群设置 →「智能群助手」→「添加机器人」→「自定义」。
2. 安全设置选一种。选「加签」的话会给你一串 `SEC...` 开头的密钥，记下来。
3. 复制 Webhook 地址。
4. 填进设置中心，有密钥就一起填，点「测试此通道」。

## 字段

| 字段 | 说明 |
|---|---|
| `webhook` | 机器人地址，形如 `https://oapi.dingtalk.com/robot/send?access_token=xxx` |
| `secret` | 加签密钥。安全设置选了「加签」才需要填 |

## 加签怎么算

程序在发请求前把 `timestamp` 和 `sign` 拼到 URL 上。算法是把
`时间戳 + 换行 + 密钥` 用 HMAC-SHA256 签名（密钥当 key），base64 之后 URL 编码。

这一步不用你管，填了 `secret` 就自动做。返回 310000 一般是签名对不上，
检查密钥有没有复制完整。

## 这个通道的坑

- 安全设置有三种，选错就发不出去。自定义关键词、加签、IP 地址段。关键词方式要求消息里含指定词，本程序的标题里不一定有，所以推荐加签。
- 每个机器人每分钟 20 条。超了会限流，返回 130101。
- markdown 标题会被单独渲染。程序把通知标题放进 `### 标题` 那一行，所以手机上看到的第一个大字段落就是标题。
