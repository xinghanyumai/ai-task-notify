# 微信测试号（wxmp）

消息直接进微信聊天列表，手机锁屏也会弹通知。免费，不限条数，不用实名，不用装 App。
配置大概两分钟。

这是主力推荐的通道，为什么不用第三方推送平台见
[ADR-003](../adr/ADR-003-wechat-sandbox-over-push-platforms.md)。

## 原理

微信官方有个模板消息接口：

```
POST https://api.weixin.qq.com/cgi-bin/message/template/send?access_token=...
{
  "touser": "你的 openid",
  "template_id": "模板 ID",
  "data": {"title": {"value": "..."}, "content": {"value": "..."}}
}
```

完整链条三步：你关注某个公众号，微信给你一个 openid，公众号用 openid 发模板消息给你。

卡点在第一步。正式服务号需要企业主体认证，个人申请不下来，很多第三方推送平台
就是靠替你把这一步跑通来收费的。

微信给开发者留了另一条路，叫公众号测试号（sandbox）。同一个接口，个人微信扫码就能拿到，
免费，不限条数，模板内容自己随便写。它是官方给开发者调试用的，长期可用。

本项目直连这个接口，还额外做了自动拉取 openid（调 `cgi-bin/user/get`），
你连 openid 都不用复制。

## 第一步：拿 appID 和 appsecret

浏览器打开 <https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login>，
微信扫码登录。页面上方就是 appID 和 appsecret，直接复制。

## 第二步：关注这个测试号

同一页面往下滚，有个「测试号二维码」，用同一个微信扫码关注。

这一步必须做，否则微信不让给你发消息，会返回 43004。

## 第三步：建模板

这一步决定手机上显示成什么样，别跳过。

页面下方找到「模板消息接口」，点「新增测试模板」。

标题填 `AI任务状态`。内容填下面这段，原样复制，一字不能改：

```
状态：{{title.DATA}}
项目：{{project.DATA}}
详情：{{detail.DATA}}
补充：{{detail2.DATA}}
补充：{{detail3.DATA}}
时间：{{time.DATA}}
```

保存后会得到一个模板 ID，是一串字母数字。

### 为什么详情要写成三个变量

微信卡片里一个变量只占一行。想让详情多显示几行，唯一的办法就是多写几个详情变量，
程序会把长文本按显示宽度切成几段，一段填一个变量。上面这个模板详情能占三行，
大约 54 个汉字。

只想要两行就删掉一个 `补充：` 行，只留一行也行。模板声明了哪些变量程序就填哪些，
多一个少一个都不影响。支持的变量名是 `detail`、`detail2`、`detail3`、`detail4`，
最多四行。

为什么不用 `\n` 换行，见 [ADR-005](../adr/ADR-005-multi-variable-over-newline.md)。

### 三条硬规则

每个 `{{变量.DATA}}` 前面必须有「标签：」。微信只认「标签：变量」这种写法。
把变量单独放一行，微信根本不会替换，消息正文就是一片空白，卡片上只剩模板标题。

```
{{title.DATA}}          渲染为空
项目：{{project.DATA}}   正常
```

症状是「收到了消息，但内容全空，或者只显示一个词」，而接口返回的是 `errcode: 0`，
看起来像发送成功，极具迷惑性。

标题创建后不能改，它就是手机上的第一行。标题留成 `test` 的话，每条通知第一行
永远都是 `test`，跟发什么内容无关。当初为了拿 openid 随手建的那个模板，删掉重建一个就行，
测试号最多 10 个模板，够用。建好新模板后跑 `selftest.py --adopt`，它会自动把配置切过去。

别用 `\n` 换行，它会把后面的内容整段吃掉。网上（包括微信官方《模板消息运营规范》
第四条）都写着旧模板样式可以用 `\n` 换行，但那是给老卡片写的。现在测试号建的模板
走的是新版卡片（卡片上会多一行日期），实测往值里塞 `\n` 之后不会换行，
而且换行符之后的全部内容直接消失，连省略号都没有。

所以本程序不碰 `\n`，改成「一个变量一行」。切段时做了两件中文排版该做的事：
行首不出标点（逗号句号断到行首就吞掉），英文单词不劈开
（`sys.stdin.buffer` 不会变成 `sys.stdin.bu` 加 `ffer`）。值区宽度按模板里实际的
标签长度算，写「详细信息：」就比「详情：」少放一个字。

字段名不是固定的，程序会读模板定义并按变量名填充，所以也可以用
`{{first.DATA}}`、`{{keyword1.DATA}}`、`{{remark.DATA}}` 这类模板库写法。
`first` 和 `remark` 是保留字段，可以不跟冒号。

拿不准时跑 `selftest.py --wxmp`，它会逐行告诉你哪一行会空白、详情实际折成几行。

## 第四步：填进设置中心

回到设置中心，选「微信测试号」，打开右上角开关，填 appID、appsecret、模板 ID。

openid 可以留空，程序会自动取第一个关注者，也可以点「自动获取 openid」。
拿到 openid 之后存在 `state/token_cache.json` 里，ACL 已经收紧。

## 第五步：测试

点右下角「测试此通道」。手机微信应该立刻弹出消息。

## 字段

| 字段 | 说明 |
|---|---|
| `appid` | 测试号页面上方的 appID |
| `secret` | 测试号页面上方的 appsecret |
| `template_id` | 新建模板后得到的那串字母数字 |
| `openid` | 留空则自动取第一个关注者 |
| `url` | 填了卡片可点击跳转，不填就点不动，这是微信的设计 |
| `wrap` | 详情自动折行。关掉后只填第一个详情变量，其余留空 |

## 这个通道的坑

- 昵称和头像改不了。测试号没有独立后台，昵称 `wxd_xxxx的接口测试号` 由 appid 派生，头像也不可设置。想要好看的名称和头像只能注册订阅号（个人可注册，但用不了模板消息）、注册服务号并做微信认证（需企业资质，认证费 300 元/年），或者改用 [企业微信自建应用](wecom-app.md)。个人自用的话测试号仍是性价比最高的选择。
- 它是「开发测试」定位，官方不承诺永久不变。接口哪天调整了，先用 `selftest.py --status` 确认，再换企业微信自建应用，同样免费免实名。
- token 有配额。接口每天有获取 access_token 的次数限制，本程序把 token 缓存到 `state/token_cache.json` 复用，遇到 40001、40014、42001 这类 token 失效错误会刷新重试一次。
- `errcode: 0` 不等于收到。关注测试号的微信和 openid 必须是同一个，微信里也不能把这个号设成「不提醒」。这两件事接口都不管，只能你自己核对。
