# 企业微信自建应用（wecom_app）

想要 markdown 加粗、标题、列表，用这个。免费，不限条数，不用实名。
配置比微信测试号多两步，换来的排版自由度高得多。

## 申请步骤

1. 打开 <https://work.weixin.qq.com/> 注册。选「团队」，微信扫码，不需要营业执照。
2. 管理后台进「我的企业」，页面底部复制**企业 ID**。
3. 进「应用管理」→「自建」→「创建应用」，填个名字和 logo，创建后记下 **AgentId**
   和 **Secret**。Secret 只显示一次，没存下来就点「查看」重新生成。
4. 在应用详情页的「可见范围」里把自己加进去。不加的话发消息会返回 81013。
5. 手机装企业微信 App，用同一个微信扫码登录。

想直接在微信里收，去后台「我的企业」→「微信插件」→ 扫码关注。
之后企业微信的消息会同步到微信里，不用单独开 App。

## 填进设置中心

选「企业微信自建应用」，填企业 ID、Secret、AgentId 三项，收件人保持 `@all`。
点「测试此通道」。

## 字段

| 字段 | 说明 |
|---|---|
| `corpid` | 企业 ID，后台「我的企业」页面底部 |
| `secret` | 应用的 Secret |
| `agentid` | 应用的 AgentId，纯数字 |
| `touser` | 收件人，默认 `@all`。多人用 `\|` 分隔，如 `zhangsan\|lisi` |

## 这个通道的坑

- Secret 只显示一次。没记下来就去后台重新生成，旧的立刻失效。
- 可见范围不包含自己就发不出去。返回 81013 基本就是这个原因。
- agentid 必须是数字。填成字符串或者带空格会返回 40056。
- token 缓存复用。和微信测试号一样，遇到 40014、42001 这类 token 失效错误会刷新重试一次。
- markdown 语法有限。支持标题、加粗、行内代码、引用、链接，不支持表格和图片。单条消息按字节截断到 4000 以内，超了会被截掉而不是拆成两条。
