# 企业微信群机器人（wecom_bot）

已经有企业微信的话，这是最稳的一条路。建个群，加个机器人，复制 Webhook。

## 申请步骤

1. 企业微信群聊 →「…」（更多）菜单 →「群机器人」→「添加机器人」。
2. 起个名字，创建后会给出一个 Webhook 地址。
3. 复制整个地址，填进设置中心的 `企业微信群机器人` 通道，点「测试此通道」。

## 字段

| 字段 | 说明 |
|---|---|
| `webhook` | 群机器人地址，形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx` |

只有一个字段。key 就在 URL 里，不用单独填。

## 这个通道的坑

- Webhook 地址就是凭证。谁拿到都能往群里发消息。贴到聊天窗口或者提交到仓库 之前先想想，泄露了就在群机器人设置里「重新获取」。
- 群机器人有频率限制。每个机器人每分钟 20 条，超了返回 45009。本程序默认限流是 4 条每分钟，正常不会撞上。
- markdown 只支持一部分语法。标题、加粗、行内代码、引用、链接能用，表格和图片不行。单条消息按字节截断到 4000 以内。
- 机器人只能在群里用。想私聊收通知，走[企业微信自建应用](wecom-app.md)。
