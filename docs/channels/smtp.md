# 邮件（smtp）

最通用的一条路，几乎不会失效。缺点是配置比别的通道麻烦，而且邮件到手机
不一定立刻弹提醒。

## 申请步骤

以 QQ 邮箱为例：

1. 网页版邮箱 →「设置」→「账号」→ 开启「IMAP/SMTP 服务」。
2. 按提示发一条短信，会得到一串**授权码**。注意这不是你的登录密码。
3. 填进设置中心：`smtp.qq.com`、端口 `465`、勾上 SSL、账号填完整邮箱、
   密码填授权码、收件人填自己的邮箱。
4. 点「测试此通道」。

Gmail 用 `smtp.gmail.com`、端口 `587`、不勾 SSL（走 STARTTLS），
密码填应用专用密码。163 邮箱是 `smtp.163.com`、端口 `465`。

## 字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `host` | `smtp.qq.com` | SMTP 服务器地址 |
| `port` | `465` | 465 配 SSL，587 配 STARTTLS |
| `ssl` | `true` | 勾上走 `SMTP_SSL`，不勾走 `SMTP` 加 `starttls()` |
| `user` | 空 | 登录账号，一般是完整邮箱 |
| `password` | 空 | 授权码或应用专用密码，不是登录密码 |
| `to` | 空 | 收件人，留空则发给 `user`。多个用逗号或分号分隔 |

## 这个通道的坑

- 填登录密码一定失败。国内主流邮箱都要授权码，QQ 和 163 都是。报 `SMTPAuthenticationError` 就是这个原因。
- 端口和 SSL 要配对。465 必须勾 SSL，587 必须不勾（程序会自动 STARTTLS）。配错了会卡在连接阶段然后超时。
- 邮件头会被压成单行。标题、发件人、收件人里的换行会被压平，这是为了防止有人用换行伪造额外的邮件头（比如偷偷加一个 `Bcc`）。
- 发件人名字固定是「任务通知」。想改只能改代码，没做成配置项。
- 邮件到手机不一定即时。手机邮件 App 的拉取间隔决定了延迟，指望它像微信一样秒到不现实。要即时提醒用微信测试号或 Bark。
