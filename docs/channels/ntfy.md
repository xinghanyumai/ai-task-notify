# ntfy（ntfy）

安卓和桌面都能用，零注册，免费。公共服务器在国内偏慢，能自建就自建。

## 申请步骤

1. 手机装 ntfy App（Play 商店、F-Droid 都有）。
2. 起一个别人猜不到的 topic，比如 `wbn-x7k2m9q4`。topic 就是密码，谁订阅了谁就能收到。
3. 设置中心选 `ntfy`，填 topic，点「测试此通道」。
4. 在 App 里订阅同名 topic。

## 字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `server` | `https://ntfy.sh` | 公共服务器。自建的话换成自己的地址 |
| `topic` | 空 | 订阅名，随便起，但要好猜不到 |
| `priority` | `3` | 1 到 5，程序会夹在这个范围内。5 是最高优先级 |
| `tags` | `robot` | 逗号分隔，会显示成通知上的小标签 |

## 这个通道的坑

- topic 就是凭证。公共服务器上没有鉴权，任何人知道 topic 都能订阅和发送。起得随机一点，别用 `test`、`notify` 这类词。
- 公共服务器会丢历史消息。免费额度下消息只保留一段时间，App 没联网的时候 可能错过。自建服务器可以自己设保留策略。
- 国内访问公共服务器偏慢。慢到不能接受就自建，`server` 填自己的地址。自建时如果要鉴权，把用户名密码写进 URL，形如 `https://user:pass@ntfy.example.com`。
- `priority` 填 5 会绕过勿扰模式。只在真需要吵醒你的时候用。
